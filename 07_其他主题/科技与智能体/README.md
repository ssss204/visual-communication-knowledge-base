# 科技与智能体

这个栏目保存人工智能、智能体（AI agents）、大模型应用、行业标准和科技产业政策资料。

## 记录原则

- 优先记录工信部、中国人工智能学会等官方或专业来源。
- 区分政策原文、企业公告、媒体报道和分析者观点。
- 记录发布日期、来源链接和“为什么重要”，不把融资传闻或市场热词当作事实。
- 技术文章只保存必要摘要，不复制受版权保护的完整内容。

## 每日资讯

每日扫描结果统一归档在 [每日资讯](../每日资讯/README.md) 中，标题按日期命名；本栏目用于沉淀不容易过期的概念、标准和技术路线。

公司观察名单见 [机器人与智能体公司观察清单](公司观察清单.md)。名单用于学习和信息核验，不构成投资推荐。

## 重点问题

1. 智能体能替用户完成哪些连续任务？边界和失败模式是什么？
2. 哪些能力来自模型，哪些来自工具、数据、权限和工作流？
3. 政策、标准和产业采购会怎样影响落地？
4. 对视觉传达专业，哪些应用能改善调研、灵感整理、设计迭代或作品表达？
