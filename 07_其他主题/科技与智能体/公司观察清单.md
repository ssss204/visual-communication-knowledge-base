# 机器人与智能体公司观察清单

## 使用说明

这是一份用于学习产业趋势的观察名单，不是股票推荐、估值结论或“看好名单”。“列入观察”只表示公开信息较多、技术或商业化路线值得持续了解；公司能否成功仍取决于产品质量、成本、客户、现金流、监管和竞争。

每日任务只记录有日期、标题、来源链接和可核验事实的新增信息。媒体报道、企业宣传和作者观点必须与官方公告分开；私人公司的融资、订单和估值传闻没有原始来源时不记录为事实。

## 评估框架

每次看到公司新闻，先按五个问题记录：

1. 这是产品发布、技术展示、客户部署、融资、政策还是传闻？
2. 证据来自公司原文、监管披露、政府文件，还是媒体转述？
3. 事件解决了什么问题，距离稳定商业收入还有几步？
4. 成本、可靠性、供应链、数据安全和监管风险是什么？
5. 哪个事实出现时，我会修正对这家公司的判断？

## 与视觉传达学习的连接

机器人公司的产品视频常常强调“会做什么”，但视觉传达学习应继续追问：目标用户是谁、任务流程是否清晰、交互反馈是否可理解、品牌叙事是否超出了实际能力。可以把每月一条公司动态做成一页信息图或 3 分钟口头汇报。

## 边界

- 私人公司通常没有完整公开财报；不能用媒体估值或融资传闻代替经营事实。
- 港股上市不等于低风险；公告、财报和股价仍需独立分析。
- 本清单不推荐买入或卖出任何股票，不提供目标价，也不执行交易。
