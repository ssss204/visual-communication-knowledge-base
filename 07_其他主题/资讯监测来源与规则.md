# 资讯监测来源与规则

## 目标

每天用有限时间获取四类信息：智能体与科技、中国经济与政策、电子元件产业、A 股市场与上市公司信披。结果写入 `07_其他主题/每日资讯`，重要且稳定的知识再归入对应主题栏目。

## 固定来源

### 智能体与科技

1. [工业和信息化部](https://www.miit.gov.cn/)：人工智能、数字经济、电子信息制造业政策和通知。
2. [中国人工智能学会](https://www.caai.cn/)：学术、标准、会议和行业共识。
3. [量子位](https://www.qbitai.com/)：产品和产业动态线索；重要事实回到官方或企业原始来源核验。

### 中国经济与政策

1. [国家统计局](https://www.stats.gov.cn/) 与 [国家数据平台](https://data.stats.gov.cn/)：GDP、CPI、工业、消费、投资等统计数据。
2. [中国人民银行](https://www.pbc.gov.cn/)：货币政策、金融统计和利率相关信息。
3. [国家发展和改革委员会](https://www.ndrc.gov.cn/)：宏观规划、产业政策和稳增长措施。
4. [中国经济网](https://www.ce.cn/)：官方经济媒体解读，只作补充，不替代原始数据。

### 电子元件

1. [工业和信息化部](https://www.miit.gov.cn/)：电子信息制造业、半导体和产业政策。
2. [中国电子报](https://www.cena.com.cn/)：电子元件、半导体和产业链动态；报道中的数字尽量回查原始来源。
3. [巨潮资讯](https://www.cninfo.com.cn/)：上市公司公告、定期报告和投资者关系信息。

### A 股与市场

1. [巨潮资讯](https://www.cninfo.com.cn/)：法定信息披露和公司原始公告。
2. [上海证券交易所](https://www.sse.com.cn/)：交易规则、监管信息和上市公司资料。
3. [深圳证券交易所](https://www.szse.cn/)：交易规则、监管信息和上市公司资料。
4. [证券时报](https://www.stcn.com/)：市场新闻和监管动态补充；不把评论或标题当作买卖依据。

## 每日执行目标

- 每天 09:00（中国标准时间）检查以上来源；每天最多整理 8 条，四个方向尽量各有覆盖。
- 优先选择最近 48 小时内的新内容；没有新内容时不为了凑数重复旧闻。
- 每个方向最多 2 条，先官方/一手，再专业媒体；同一事件只保留一条主记录并列出交叉来源。
- 只读取公开页面，不登录、不绕过验证码、不抓取付费墙内容，不下载或保存整篇文章和完整字幕。
- 每条记录写清：标题、作者/机构、发布日期、来源链接、已确认事实、对学习的意义、待核验问题、关键词。
- A 股和电子元件部分只做信息整理与风险教育，不推荐具体股票、不写目标价、不执行开户或买入操作。
- 如果来源不可访问、页面需要人工验证或事实无法核验，记录原因并跳过，不编造摘要。

## 去重与归档

去重状态保存在 `99_归档/自动化状态/每日资讯监测.md`。以来源、标题、发布日期和原文链接组合判断重复；每次成功写入简报后才更新状态。若电脑关机或一次运行失败，下一次应检查最近 7 天，尽量补齐遗漏而不是重复造稿。

## 质量检查

1. 来源链接可打开，日期和统计期明确。
2. 官方事实、媒体观点和 AI 独立解释分段书写。
3. 不把“利好、风口、必涨、稳赚”等宣传词改写成事实。
4. 检查 Markdown 相对链接和 `git diff --check`。
5. 只提交本次生成的简报、索引和状态文件，推送前确认没有带入用户的其他改动。
