# 阅读与书籍

用于保存书目、讲书视频笔记、主题阅读路线和读后实践。这里记录的是对来源的提炼与个人理解，不替代阅读原书。

## 分类导航

- [讲书视频 / oMel](讲书视频/oMel/README.md)：抖音讲书博主 oMel 的视频摘要、辨析和行动练习。
- [讲书视频 / 访谈](讲书视频/访谈/README.md)：访谈类视频的章节摘要、观点辨析和能力练习。

## 使用原则

- 记录作者、链接、发布日期、获取方式和查看日期。
- 把“来源观点”和“我的理解”分开，无法从来源确认的内容明确标注。
- 优先提炼能用于学习、设计实践和个人成长的方法，不保存完整逐字稿。
- 重要结论回到原书或可靠资料复核后再引用。
