# 股票与投资

这个栏目用于保存金融市场、股票、基金、债券和个人风险管理等学习资料。

## 学习原则

- 先理解基本概念，再接触具体产品和交易方法。
- 区分事实、作者观点和自己的理解，重要结论尽量交叉核实。
- 记录作者、发布日期、阅读日期和原始链接。
- 不因为一篇文章或一个人的观点作出投资决定。
- 不记录“必涨”“稳赚”等无法验证的结论，也不推荐具体股票。

## 建议学习顺序

1. 金融市场与常见金融工具。
2. 收益、风险、流动性和投资期限。
3. 股票与基金的基本运作方式。
4. 财务报表、估值和行业分析。
5. 资产配置、分散风险和行为偏差。
6. 用模拟记录或小额实践检验自己的理解。
