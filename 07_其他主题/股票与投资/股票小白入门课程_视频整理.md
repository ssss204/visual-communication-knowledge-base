## 重点知识地图

### 1. 股票是什么

股票代表对上市公司的部分所有权。投资者的回报可能来自分红和价格变化，但两者都不保证发生。理解股票时先回答：

- 公司卖什么，谁在付钱？
- 公司怎样把收入变成利润和现金流？
- 行业竞争、治理和政策有哪些风险？
- 当前价格是否已经反映了过高的预期？

把股票只看成“会跳动的代码”容易被短期行情牵着走；把它看成企业权益，才有机会建立研究和复盘习惯。

### 2. 交易规则要先核验

视频的第二部分以“交易规则”为主题。A 股具体制度会调整，实际下单前应以开户券商、上海/深圳证券交易所和中国结算的最新规则为准。入门时至少建立以下清单：

| 事项 | 初学者要弄清楚什么 |
| --- | --- |
| 交易时段 | 何时可以委托、何时撮合、何时休市；不同市场和产品可能不同 |
| 最小交易单位 | 普通股票通常按 100 股一手理解，但不同板块、产品和卖出零股规则需核验 |
| 价格限制 | 涨跌幅限制、特殊处理股票和新股规则可能不同 |
| 订单与成交 | 委托不等于成交；价格、时间和市场规则会影响成交 |
| 交收与可用资金 | 买入后何时可卖、卖出后资金何时可取，按账户和市场规则确认 |
| 费用 | 佣金、印花税、过户费及最低收费会影响小额交易结果 |

“看懂按钮”不等于理解风险。任何开户、转账或下单之前，应先在券商帮助中心核对最新费率和业务规则。

### 3. 术语学习方法

不要只背缩写。建议把每个术语写成“定义—它回答什么问题—不能说明什么”的三栏卡片。

| 术语类别 | 示例 | 正确的学习问题 |
| --- | --- | --- |
| 价格与成交 | 开盘价、收盘价、最高价、最低价、成交量、成交额 | 今天价格和成交活跃度发生了什么变化？ |
| 公司与估值 | 市值、市盈率、市净率、每股收益 | 市场用什么价格评价公司？这个指标的分母和口径是什么？ |
| 行情状态 | 涨停、跌停、停牌、复牌、除权除息 | 价格变化是否包含制度或分红因素？ |
| 资金与持仓 | 可用资金、可取资金、持仓、成本价、浮动盈亏 | 这个数字是实时估算、已结算结果，还是账户展示口径？ |

市盈率等指标不能单独决定买卖。利润受周期、一次性项目和会计口径影响，必须结合现金流、行业和估值区间阅读。

### 4. K 线、均线和趋势的边界

- **K 线**把一段时间的开盘、收盘、最高、最低价格压缩成一个图形，适合描述历史价格行为。
- **均线**是过去若干期价格的平均值，用于观察价格相对位置和趋势平滑程度；周期不同会得到不同信号。
- **趋势**是对一段价格运动方向的描述，不是对未来的保证。

技术图形容易给人“已经找到答案”的错觉。更稳妥的用法是把它当作观察和记录工具，并同时写出基本面、估值、流动性和反例。不要因为一根 K 线或一次“金叉”就推断必涨。

### 5. 开户、买入、卖出与销户的流程意识

页面第五部分以完整交易流程为主题。学习时把流程拆成四个可检查节点：

1. **开户前**：确认本人身份、账户类型、费用、风险测评和适当性要求。
2. **下单前**：确认证券代码、名称、价格、数量、买卖方向和资金来源。
3. **成交后**：保存成交记录，理解持仓成本、费用、交收日期和可卖/可取状态。
4. **复盘或退出**：记录当初理由、实际结果和费用；不再使用时再了解销户条件和流程。

本笔记不替你开户、不代你下单，也不根据视频推荐具体股票。操作界面因券商和产品而异，遇到不确定字段应先咨询券商官方客服。

### 6. 国债逆回购的定位

国债逆回购可以理解为在约定期限内出借资金、收取约定利息的一类交易工具。它不是“股市余额宝”的无风险替代品，仍要关注：

- 交易品种、期限、交易时间和最低金额；
- 到期资金何时可用、何时可取；
- 实际年化报价会变化，展示收益不等于最终净收益；
- 佣金、节假日和资金占用对短期收益的影响。

具体规则和费率必须以交易所、券商的最新说明为准，不把视频标题中的宣传性表述当成收益承诺。

## 给王瑞轩的学习版本

### 100 元实验的适用边界

100 元可以作为“认识账户、记录费用和观察情绪”的学习实验费，但不适合频繁买卖：

- 普通 A 股常见的 100 股最小单位会限制可选标的；
- 佣金最低收费、印花税和价格波动可能让小额交易的结果主要反映费用和随机波动；
- 不得使用学费、生活费、应急金、借款或影响开学生活的钱；
- 如果无法按规则买入合适产品，就继续模拟，不必为了“实盘”强行下单。

### 一页学习记录

每次观看或研究后只写一页：

1. 今天新增的 3 个术语是什么？
2. 我能否用自己的话解释它们？
3. 哪条规则或数据还需要去官方来源核验？
4. 如果做模拟交易，买入理由和反对理由各是什么？
5. 30 天后用什么事实判断自己当时是否想错？
