## 核心学习框架

### 1. 先问“我买的到底是什么”

股票不是一种固定利息产品，也不是只要买入就会产生收益的储蓄账户。买入股票通常意味着获得公司的一部分权益，结果取决于企业经营、市场估值、交易价格和持有期间。学习时写下：

- 公司靠什么收入和现金流生存？
- 我承担的是公司经营风险、市场波动风险，还是流动性风险？
- 我需要这笔钱的时间是否早于可能的持有周期？

这三个问题比先学“哪个指标买入”更重要。

### 2. “拿多少钱”是风险管理，不是押注比例

视频专门设置“投资计划”章节，提醒学生先安排资金。对大学生尤其要区分：

| 资金 | 处理原则 |
| --- | --- |
| 学费、房租、生活费 | 不投入股市 |
| 应急金和短期必须使用的钱 | 保持高流动性，不承担股票波动 |
| 借款、信用贷、他人托付资金 | 不用于试错 |
| 即使亏完也不影响基本生活的闲钱 | 才能考虑用于学习，仍需设上限 |

你之前提到的 100 元，更适合作为一次有限的学习实验：记录开户/交易流程、费用和情绪，不把它当作快速赚钱计划。若 100 元无法满足最小交易单位或费用条件，就使用模拟账户。

### 3. 交易规则要用官方资料确认

章节标题表明视频会介绍交易规则，但规则会随市场、板块、产品和时间调整。至少核对：交易时段、最小交易单位、涨跌幅限制、委托与成交、交收时间、可用/可取资金和佣金税费。普通 A 股常按 100 股一手理解，但不能把这一概括套用到所有产品。

下单前采用“二次确认”：

1. 证券代码和名称是否一致？
2. 买卖方向、价格、数量和账户余额是否正确？
3. 订单是已报、部分成交还是全部成交？
4. 成交记录中的费用和交收日期是什么？

遇到券商界面与视频不同，以券商官方帮助和交易所最新规则为准。

### 4. 术语要翻译成自己的话

“人话翻译”适合降低入门门槛，但理解术语不能只停留在口语比喻。建议用以下模板：

> **术语**：它的正式定义是什么？
> **它回答的问题**：投资者为什么要看它？
> **它不能回答的问题**：哪些结论不能从它单独推出？
> **例子**：用一家熟悉公司或一段历史行情说明。

例如，“成交量增加”只能说明一段时间内成交活跃度发生变化，不能单独推出“主力在买入”或“明天必涨”。“市盈率低”可能代表便宜，也可能代表市场预期盈利会下降，必须看利润质量、行业周期和现金流。

## 把个人经验变成可复盘的方法

### 交易前卡片

- 这笔操作的目标是学习什么，而不是赚多少？
- 我为什么选择这个产品？有哪些反对理由？
- 最长持有多久？什么事实出现时我会承认判断失效？
- 亏损多少会影响我的生活或情绪？如果会，就不应投入这笔钱。

### 交易后日志

- 委托、成交、费用和交收记录；
- 当时的事实与当时的猜测，分开书写；
- 一周后、一个月后各复盘一次；
- 评价“是否遵守计划”，不要只用盈亏评价自己。

## 给视觉传达专业学生的连接

股票学习可以顺便练习设计专业需要的表达能力：

- 用一张信息图解释“股票—收益—风险—资金期限”的关系；
- 用 3 分钟口头汇报讲清一家公司如何赚钱；
- 把一次模拟交易做成案例复盘，说明证据、取舍和下一步；
- 练习区分事实、作者观点和自己的判断，这也是作品汇报和面试中的核心能力。
