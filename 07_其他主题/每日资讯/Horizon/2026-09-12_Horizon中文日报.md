hackernews · michalwarda · 9月11日 11:15 · [社区讨论](https://news.ycombinator.com/item?id=49656471)

**「背景」** RTK（Rust Token Killer）是一款开源 CLI 工具，其定位是在命令输出进入 AI 上下文窗口之前对其进行压缩，官方宣称可减少 60%–90% 的 token 用量且无需修改配置，并支持 17 种 AI 编程工具，通过将 shell 命令重写为 rtk 等价形式来减少 agent 读取的 bash 输出。围绕这类“token 节省”插件，JetBrains 等机构已开展成对的 A/B 基准测试，逐一检验其真实效果。

**「影响」** 对于考虑采用 RTK 的开发者，该基准测试表明其宣称的节省并不可靠：在 Terminal-Bench 2.1 上，Fable 的节省主要来自单个任务，跨任务并不成立，因此作者不建议将 RTK 作为通用降本工具。社区反馈还指出，RTK 在输出经 \`tail\` 等管道截断时会虚报节省，并因默认持久化节省统计而破坏沙箱隔离。

**「社区讨论」** 评论普遍质疑此类 token 节省“技巧”是噱头，认为若真有简单的预处理优化，AI 实验室早就会自行上游实现，并呼吁建立独立基准测试。有开发者表示，用专用本地代码嵌入模型索引代码库在其基准中显著减少了 token 使用和墙钟时间，但 CPU 开销较高且效果依赖具体场景。也有评论认为效果取决于任务类型。
