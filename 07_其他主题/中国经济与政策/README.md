# 中国经济与政策

这个栏目保存中国宏观经济、货币政策、产业政策、监管政策和政策传导的学习资料。

## 记录原则

- 以国家统计局、人民银行、国家发展改革委等一手来源为基准。
- 同一事件分开记录“官方事实”“媒体解读”“个人推断”。
- 记录数据口径、统计期和发布日期，避免把同比、环比和累计值混为一谈。
- 政策文件说明的是目标、工具和适用范围，不等于必然的市场涨跌。

## 每日资讯

每日扫描结果统一归档在 [每日资讯](../每日资讯/README.md) 中；需要长期复习的概念再整理为独立笔记并链接回来源。

## 重点问题

1. 这项政策解决什么问题，使用了什么工具？
2. 影响首先通过哪个部门、行业或资金渠道传导？
3. 哪些内容已经发生，哪些只是目标或预测？
4. 数据是否存在季节性、基数效应或统计口径变化？
