# 经济学

这个栏目用于保存经济学的基本概念、分析方法、市场机制和宏观经济知识。

## 学习原则

- 先问清楚假设，再使用模型解释现实。
- 区分“是什么”的实证判断与“应该怎样”的规范判断。
- 画出因果链，避免只背结论或公式。
- 经济效率、社会公平和个人利益是不同的问题，不能混为一谈。
- 教材模型是思考工具，不是对现实世界的完整复制。
