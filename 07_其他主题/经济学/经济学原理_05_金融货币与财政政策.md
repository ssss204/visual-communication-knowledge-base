## 一、储蓄、投资与金融体系

### 封闭经济中的恒等式

从支出法 GDP 开始：

```text
Y = C + I + G + NX
```

封闭经济没有净出口，`NX = 0`，所以：

```text
Y = C + I + G
S = Y - C - G
因此 S = I
```

这里的 `S = I` 是国民收入账户中的会计恒等式，不是说每个家庭的储蓄都直接等于自己的投资，也不是对开放经济资金流动的完整描述。

### 私人储蓄与公共储蓄

设 `T` 为税收减转移支付：

```text
私人储蓄 = Y - T - C
公共储蓄 = T - G
国民储蓄 S = (Y - T - C) + (T - G)
```

- `T > G`：政府预算盈余，公共储蓄为正。
- `T < G`：政府预算赤字，公共储蓄为负。

金融市场与金融中介把储蓄者的资金连接到购买新设备、建筑和存货的投资者。宏观经济学中的“投资”指新增实际资本，不等同于个人买卖已有股票。

## 二、货币的时间价值

### 终值、现值与复利

- **终值**：今天的资金按利率增长后，未来会有多少。
- **现值**：为了在未来获得某一金额，今天需要多少资金。
- **复利**：利息继续产生利息。

设本金为 `P`、未来金额为 `X`、每期利率为 `r`、期数为 `N`：

```text
终值 FV = P × (1 + r)^N
现值 PV = X / (1 + r)^N
```

贴现就是把未来金额换算回今天价值。实际使用还要统一利率和期数，并考虑通胀、风险、税费与现金流发生时间。

## 三、货币制度

### 货币解决什么问题

物物交换要求双方恰好都想要对方的东西，即“需求的双向一致”。货币降低了寻找交易对象和报价的成本。

货币有三项基本职能：

1. **交换媒介**：在交易中被普遍接受。
2. **计价单位**：表示价格、成本和债务。
3. **价值储藏**：把当前购买力转移到未来。

**流动性**是资产转化为交换媒介的便利程度。现金流动性高，但不是唯一的价值储藏资产。

### 商品货币与法定货币

- **商品货币**：物品本身也有非货币用途和价值，例如历史上的黄金。
- **法定货币**：主要依靠法律制度、国家信用和社会接受度流通，本身没有对应的商品内在价值。

原笔记把比特币是否属于货币归结为价值储藏能力不足。更准确地说，这仍有争议：它能否成为货币取决于是否稳定、广泛地承担交换媒介、计价单位和价值储藏三项功能，不宜一句话定论。

### 货币口径

原笔记以美国教材为例介绍 M1 和 M2：M1 偏向通货与可随时支付的存款，M2 在此基础上加入部分储蓄和近似货币资产。各国统计口径会调整，查询中国数据时应以中国人民银行当期定义为准。

## 四、银行、货币创造与杠杆

### 准备金和贷款

- **准备金**：银行收到存款后没有贷出的部分。
- **部分准备金银行制**：银行保留一部分流动性，其余用于贷款或其他资产。
- **准备金率**：准备金占相关存款的比例。

教材的简化例子中，存款、贷款再存款会扩大存款货币；在没有现金漏损、超额准备金等限制时：

```text
简单货币乘数 = 1 / 准备金率
```

这只是教学模型。现实货币创造还受贷款需求、资本监管、银行风险偏好、央行操作、支付行为和监管框架影响，不能用准备金率倒数机械预测货币供应量。

### 银行资产负债表

```text
资产 = 负债 + 所有者权益
所有者权益 = 资产 - 负债
杠杆率 = 总资产 / 银行资本
```

原笔记示例中，总资产为 1000、资本为 50，杠杆率为 20。资产价格上升 5% 会使资本从 50 增到 100；下降 5% 会把资本消耗到 0。杠杆放大资本回报，也同样放大损失，这解释了资本充足要求的重要性。

## 五、财政政策与总需求

### 财政政策

财政政策是政府对政府购买和税收水平的选择。增加政府购买会直接提高总需求，但最终变化通常不等于最初支出金额，因为存在两种相反力量。

### 乘数效应

政府支出成为居民和企业收入，其中一部分继续用于消费，再成为下一轮收入。在最简化模型中，设边际消费倾向为 `MPC`：

```text
支出乘数 = 1 / (1 - MPC)
```

如果 `MPC = 0.8`，最简模型的乘数为 5。但现实中的储蓄、税收、进口、供给约束、价格变化和政策预期都会让实际乘数偏离这个数字。

### 挤出效应

扩张性财政政策可能推高资金需求和利率，减少私人投资，这部分对总需求的抵消称为挤出效应。经济闲置程度、央行反应、融资方式和开放程度都会影响挤出强弱。

```text
政府购买增加
  -> 直接增加总需求
  -> 收入和消费继续增加：乘数效应
  -> 利率或资源压力抑制私人支出：挤出效应
  -> 最终净效果取决于当时环境
```

## 与股票学习的关系

- 真实利率影响未来现金流的贴现和资产估值。
- 通胀、货币与财政政策会影响企业成本、消费需求和市场利率。
- 银行杠杆说明为什么小幅资产损失可能迅速侵蚀资本。
- 宏观恒等式用于理解总体资金流动，不能直接推出某只股票的涨跌。
