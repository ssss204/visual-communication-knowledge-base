## 全部知识的主线

```text
稀缺资源
  -> 人必须选择
  -> 选择产生机会成本
  -> 理性决策比较边际收益与边际成本
  -> 激励改变行为
  -> 分工和贸易利用比较优势
  -> 市场通过价格协调供需
  -> 税收、市场势力和外部性可能造成效率损失
  -> 政府尝试通过规则、税收、补贴和政策改善结果
  -> GDP、CPI等指标用于观察整体经济
  -> 储蓄经金融体系转化为投资
  -> 货币、银行和财政政策影响经济活动
```

## 最重要的概念连接

| 起点 | 连接 | 结果 |
| --- | --- | --- |
| 稀缺性 | 必须取舍 | 每项决定都有机会成本 |
| 边际收益与边际成本 | 比较最后一单位的得失 | 决定是否继续行动 |
| 比较优势 | 按较低机会成本分工 | 贸易可以扩大双方可消费范围 |
| 税收 | 减少一部分互利交易 | 可能产生无谓损失 |
| 外部性 | 私人成本或收益不等于社会成本或收益 | 市场数量偏离社会最优 |
| 产品差异与少数卖者 | 企业获得一定市场势力 | 价格可能高于边际成本 |
| GDP 与 CPI | 分别衡量生产和消费者生活成本 | 帮助观察增长与通胀 |
| 储蓄与金融体系 | 把闲置资金连接到资本投资 | 支持未来生产能力 |
| 杠杆 | 放大资产变化对资本的影响 | 同时放大收益与损失 |
| 财政扩张 | 乘数效应增加需求，挤出效应抵消部分需求 | 最终影响取决于经济环境 |

## 阅读时必须保留的边界

- 模型结论依赖假设，不能脱离市场结构、时间和制度环境机械套用。
- “总福利增加”不等于每个人都获益，赢家是否补偿输家是另一个问题。
- GDP、CPI 等统计指标有明确口径，也都有测量局限。
- 货币乘数、财政乘数等公式是简化模型，不是可以直接预测现实数值的固定规律。
- 原笔记部分内容以美国教材语境为主，M1、M2、准备金制度和政策工具应结合中国现行口径另行核验。

## 学习成果检查

完成这组笔记后，应能回答：

1. 为什么所有选择都有机会成本？
2. 为什么绝对优势不决定贸易方向，比较优势才决定？
3. 税收、关税和外部性如何影响社会总剩余？
4. 垄断竞争与寡头市场为什么会产生市场势力？
5. GDP、真实 GDP、GDP 平减指数和 CPI 有什么区别？
6. 储蓄、投资、银行、货币和财政政策之间如何连接？
