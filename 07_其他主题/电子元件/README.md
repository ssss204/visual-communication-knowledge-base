# 电子元件

这个栏目保存电子元件、半导体、被动元件、显示器件、PCB、供应链和相关产业政策资料。

## 记录原则

- 优先使用工信部、中国电子报、交易所公告和企业原始披露。
- 把“行业需求”“公司订单”“产品价格”“产能规划”分开记录，不能互相替代。
- 研报中的市场规模和预测必须标注机构、发布日期与假设。
- 不因为行业热点直接推荐股票；个股信息回到巨潮资讯和交易所核验。

## 每日资讯

每日扫描结果统一归档在 [每日资讯](../每日资讯/README.md) 中；出现稳定的技术概念或产业链知识时，再拆成专题笔记。

## 重点问题

1. 这条消息属于需求、供给、价格、库存、技术还是政策？
2. 影响的是整个产业链，还是单一公司/单一产品？
3. 证据是公告、统计数据、采访，还是未经证实的传闻？
4. 对设计学习有何关联，例如显示、印刷、设备或 AI 硬件？
