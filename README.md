# 我的视觉传达知识库

这是一个以视觉传达设计学习、项目积累和就业准备为核心的个人知识库。

## 如何使用

1. 新资料先放入 `00_收件箱`。
2. 对 AI 说：`整理 E:\我的知识库\00_收件箱\某个目录`。
3. AI 会根据资料内容归类、生成摘要，并把无法确定的内容放入 `90_待整理`。
4. 重要资料请保留来源、作者和日期；个人理解写在“我的分析”部分。
5. 每完成一次课程作业，都在 `04_我的项目` 建立一份项目记录。

## 分类导航

| 目录 | 用途 |
| --- | --- |
| `00_收件箱` | 等待整理的新资料 |
| `01_设计基础` | 色彩、构成、字体、版式、设计史 |
| `02_软件技能` | Photoshop、Illustrator、Figma 等软件 |
| `03_设计案例` | 品牌、海报、包装、UI 等案例分析 |
| `04_我的项目` | 课程作业、练习、作品集项目和复盘 |
| `05_设计行业与就业` | 岗位、公司、作品集和面试资料 |
| `06_灵感素材` | 配色、字体、图片、网页和视觉参考 |
| `07_其他主题` | 心理学等非设计主题；必要时在此创建新栏目 |
| `90_待整理` | 无法确定分类或需要确认的内容 |
| `99_归档` | 过时但暂时保留的内容 |

## 笔记质量标准

- 标题能准确说明主题。
- 重要内容使用 Markdown 标题、列表或表格组织。
- 外部资料记录来源链接、作者和查看日期。
- 案例必须包含自己的分析，不只保存图片或复制原文。
- 不保存密码、密钥等敏感信息。

## GitHub 同步

本目录应关联一个 GitHub 私有仓库。修改后提交并推送，另一台电脑通过拉取获取更新。GitHub 同步文件和版本；AI 是否能读取内容，取决于当前电脑上使用的 AI 工具是否获得本地目录或仓库访问权限。
