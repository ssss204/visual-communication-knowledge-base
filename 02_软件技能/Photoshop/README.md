# Photoshop 学习区

这里保存 Photoshop 教程、操作笔记、练习过程和与视觉传达项目相关的工作流。

## 推荐学习顺序

1. 先学文档设置：分辨率、文件格式和颜色模式。
2. 再学界面、视图、选区、图层和常用快捷键。
3. 接着练习钢笔、文字和形状，建立视觉传达常用的造型与排版能力。
4. 然后学习调整图层、蒙版、滤镜、混合模式和通道。
5. 最后用课程练习题完成小项目，并写下自己的复盘。

## 文件保存建议

- 工作文件保留 PSD，并给图层、组和蒙版写清楚名称。
- 交付前根据用途导出 PNG、JPEG、PDF 等格式，不要用导出文件替代 PSD 源文件。
- 印刷项目在交付前确认尺寸、出血、颜色配置和印厂要求。
